# Monke production queue

Use approval v3 as the reference for acting, material handling and legibility. Slots below are the selected actions, not approved renders. Route each through the [plate review workflow](../../../tools/monke/REVIEW.md). The rejected pilot is retained for comparison.

| Pack pose | Performance |
|---|---|
| idle | Scratch head, look around, settle. |
| resting | Doze upright. |
| working | Sort banana bunches. |
| inspecting | Investigate with a magnifying glass. |
| editing | Hammer a beige keyboard with two index fingers and enormous confidence. |
| executing | Pull a giant lever and brace for consequences. |
| building | Stack banana blocks under an oversized hard hat. |
| transferring | Shuttle one banana at a time between two labeled baskets. |
| researching | Consult a telescope, then take a very serious note. |
| coordinating | Point at tasks while a helper quietly turns the map right-side up. |
| external | Hoist a question to a cloud in a bucket, retrieve the answer, applaud own brilliance. |
| parallel | Operate two keyboards with the hands and a third with the feet. |
| question | Raise a hand while the tail curls into a question mark. |
| approval | Approach the red button, restrain wrist with tail, wait pleadingly. Preferred benchmark is approval v3. |
| failure | Freeze holding a broken gear in each hand with an error badge. |
| completed | Do a tiny victory dance followed by an excessively formal bow. |
| setback | Slip on own banana peel, recover, get back to work. |
| interrupted | Freeze mid-typing with fingers hovering over keys. |
| compacted | Stuff a mountain of notes into a tiny coconut filing cabinet. |
| wake | Swing into the scene. |
| walking | Knuckle-walk with unnecessary determination. |
| departing | Punch a leaf timecard, wave, scamper away. |
| helper | Junior carries a tool almost as large as itself. |
| compact_work | Concentrated two-finger typing, punctuated by the occasional keyboard punch. |
| coffee | Use a banana as a phone, remember it is food, take a bite. |
| groove | Play a TV game with an Xbox-style controller and headset, then ragequit and throw the controller at the TV. |
| hat | Flex at reflection in a shiny coconut. |
| pushing | Turn an oversized gear with the whole body. |
| thinking | Pace, hands behind back, wearing an oversized thinking cap. |
| eureka | A flickering lightbulb becomes an enormous banana. |
| overheated | Start mashing keyboard, stop, carefully press one key. |
| offline | Bring disconnected vine ends together and look at viewer while tail makes a no-signal symbol. |
| low_power | Lean on a stick as eyelids gradually close. |
| still | Sit blank-faced with a loosely curled tail. Static reduced-motion drawing. |
| ready | Wait with tail showing a checkmark. |
